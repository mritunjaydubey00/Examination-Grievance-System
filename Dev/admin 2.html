Step 1: Strict Role Separation & Security Isolation

When a user logs in (e.g., Student), the system sets `currentUser` and triggers `renderPortal()`. All other role sections (`#adminPortalView`, `#facultyPortalView`) are explicitly set to hidden in DOM layout. Students cannot view or interact with administrative workflows.

Step 2: File Attachment Size Validation (<= 5MB)

The multi-file upload handler checks `file.size` against `5 * 1024 * 1024` bytes. Oversized files trigger an instant error toast and are discarded from the submission state, while valid files are converted and attached.

Step 3: End-to-End Resolution Workflow

1. Student submits grievance (Status: `Submitted`) → 2. Exam Cell Admin reviews case and forwards to Subject Faculty with instructions (Status: `Under Progress`) → 3. Faculty evaluates script/issue and submits final response (Status: `Resolved`). Real-time notifications update for student instantly.
