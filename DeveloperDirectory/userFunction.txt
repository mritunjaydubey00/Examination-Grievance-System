Included streams :- 
    > iostream : for I/O operations.
    > string : for getline function and other string operations 
    > localStorage.h : for storage of the user data in Database


Class User 
    > takes user data, all aas strings
        1. fname 
        2. lname 
        3. email
        4. phoneNumber
        5. department
        6. position 
        7. userID
        8. password
    > Friend Functions
        1. friend int makeUser(User &user);
        2. friend int userID(User &user);
        3. friend int displayUserInfo(User &user);
        4. friend int password(User &user, int choice);
        5. friend int completeProfile(User &user);
        6. friend string makeString(User &user);

int makeUser(User &user) 
    1. takes the reference to the object.
    1. Asks for first name and last name 
    2. uses getline to store then in fname and lname.

int userID(User &user)
    1. Asks for user ID 
    2. uses getline to assign the value to userID of referenced object 

int displayUserInfo(User &user)
    1. Displays the information of the user.
